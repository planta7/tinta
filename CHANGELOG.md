# Changelog

## 0.1.0 / VS Code 0.2.0

npm channel: latest. Extension channel: stable.

- Install tinta and the coordinated @tinta-lang packages from the recommended npm channel; use the stable VS Code extension.
- Use the new ink mark, wordmark and icons in Studio and VS Code.
- Read and edit with consistently aligned controls and clearer checkbox styling.
- Explore illustrated document examples and a language tour covering controls, calculations, tables and charts.
- Try Studio in the online demo, or download it to edit documents locally and work offline.
- Open Studio from the CLI without the previous npm configuration warning.
- Find installation instructions, usage examples and API guidance in every npm package README.
- Follow updated Studio and VS Code guides, with a refreshed Studio screenshot and clearer explanations of local files and exports.
- Use clearer catalog actions, search hints, diagnostics, import messages and save dialogs; export privacy warnings remain explicit.
- Report security vulnerabilities privately to roberto@planta7.io.
- Find release notes and installation links for each published version.

### Compatibility

- The language contract remains 1.0-draft.3; the source format remains 1.0. No syntax or document-meaning changes are introduced by this release.
- Node.js 24.21.0 and VS Code Desktop 1.141.0 are the supported baselines on macOS arm64, Linux arm64 and Windows x64.
- Remote workspaces, vscode.dev and Linux x64 are not supported.
- The 0.x software series is still evolving; public APIs may change before 1.0.0.
