# Changelog

## 0.1.0-dev.0 / VS Code 0.1.0

npm channel: next. Extension channel: pre-release.

- Write interactive Markdown documents with local controls, formulas, tables and charts.
- Edit documents in Studio or VS Code, and export portable interactive or static HTML.
- Use the tinta CLI and reusable @tinta-lang packages for local document workflows.

### Compatibility

- The language contract is 1.0-draft.3; the source format remains 1.0.
- Node.js 24.21.0 and VS Code Desktop 1.141.0 are the tested baselines on macOS arm64, Linux arm64 and Windows x64.
- Remote workspaces, vscode.dev and Linux x64 are not supported by this release.
