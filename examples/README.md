# Example documents

Open these documents in tinta studio or use them with the CLI to explore the language. The four featured examples have local illustrations. Save a `.tinta.zip` source bundle when you want to keep an image with its editable source; a plain `.tinta` file needs its image beside it in the matching `assets/` path. They use fictional data. Each initial result below follows the authored default answers.

| File | What it demonstrates | Initial result |
|---|---|---|
| minimal.tinta | Control, calculation and guarded prose | people=5; total=95; large-team paragraph absent. |
| article.tinta | Newsletter readership hypothesis with a computed curve and linked selection | growth=5; period=2; selected_readers=110. |
| report.tinta | Neighborhood reading report with shared view, aggregate, bar and donut | Two weekdays; total=280; average=140; selected Mon=120. |
| guide.tinta | Local workshop handout with platform-specific instructions | macOS paragraph visible; Windows/Linux absent; extra details absent. |
| chart-atlas.tinta | All controls, calculations, views, Markdown features and seven chart types | 7 figures; all series visible; period=1, format=Text. |
| all-functions.tinta | Eleven built-ins | n=3; sum=60; mean=20; count=3. |
| import-before.md / import-after.tinta | Safe literal-preserving enrichment | Same safe Markdown presentation, with two inserted escapes only. |
| local-image.tinta / local-image.tinta.zip | Source/asset portability | One hashed raster asset, exact byte preservation. |
| article.tinta.state.json | Explicit answer snapshot | growth=10 and period=2 produce selected_readers=121 when applied. |

The four featured illustrations are original local raster artwork. The one-pixel image remains a binary fixture for source/asset portability. Its source bundle contains the editable document and its raster asset; reopen it to see the same resource without a sidecar file.
