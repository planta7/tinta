# Example documents

Open these documents in tinta studio or use them with the CLI to explore the language. The four featured examples have local illustrations. Save a `.tinta.zip` source bundle when you want to keep an image with its editable source; a plain `.tinta` file needs its image beside it in the matching `assets/` path. They use fictional data. Start with a featured example, then use the smaller files to explore individual features.

| File                                      | Try this                                                                      |
| ----------------------------------------- | ----------------------------------------------------------------------------- |
| article.tinta                             | Change the newsletter growth rate and select an edition to inspect.           |
| report.tinta                              | Include weekends or raise the minimum to compare selected reading sessions.   |
| guide.tinta                               | Choose a platform to show the matching workshop instructions.                 |
| chart-atlas.tinta                         | Explore all seven chart types and see how charts share a selection.           |
| minimal.tinta                             | Change the number of people to update the monthly amount.                     |
| all-functions.tinta                       | Adjust a value and compare the eleven built-in functions.                     |
| import-before.md / import-after.tinta     | Compare Markdown with a tinta copy that preserves literal examples.           |
| local-image.tinta / local-image.tinta.zip | Compare an image beside a source file with an image inside a portable bundle. |
| article.tinta.state.json                  | Apply saved answers with the CLI: growth 10 and edition 2 give 121 readers.   |

The four featured illustrations are original local raster artwork. The one-pixel image demonstrates a minimal portable bundle containing source and an image. Reopen the bundle without its sidecar file to try it.
